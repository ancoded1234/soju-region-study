# 데이터 품질 및 검수 보고서

검수 기준일: 2026-10-19

## 사용 자료

- 주 자료: 트렌드모니터, 엠브레인 구매딥데이터(DD.B), 2026년 5월 MAT 기준 가정용 소주류 구매액 순위 TOP 7.
- 기간 표기: MAT는 최근 12개월 이동 합계/기간을 뜻한다. 원문은 2026년 5월 MAT로 표시한다.
- 범위: 전국 및 수도권·충청권·전라권·경상권·강원권. 제주도는 독립 권역으로 제시되지 않았다.
- 전사: 게시 페이지의 순위 인포그래픽을 직접 확인해 6개 그룹의 1~7위, 총 42행을 `data/regional_top7_2026_mat.csv`에 입력했다.
- 보조 설명: Puppia 글은 맥락 확인에만 참고하며 순위 원자료로 사용하지 않았다.

## 검증 결과

- 6개 그룹 × 7위 = 42행이며, 각 그룹에 순위 1~7이 한 번씩 존재한다.
- 권역별 1위: 수도권 참이슬 후레쉬, 충청권 참이슬 후레쉬, 전라권 참이슬 후레쉬, 경상권 진로, 강원권 참이슬 후레쉬.
- 따라서 동일한 1위 브랜드가 나타난 권역은 5개 중 4개다.
- 전국 순위 1~3위: 참이슬 후레쉬, 처음처럼, 진로.
- 원문이 공개한 것은 순위와 브랜드명이다. 지역별 구매액의 원수치, 시장 점유율, 판매 병 수, 패널 수와 구성, 표집·가중 세부 방법은 수집 자료에서 확인되지 않았다.
- 원문 주석은 구매 추정액이 실제 결제 기반 추정치이며 공식 매출액이나 소비자 선호도 순위와 다를 수 있음을 밝힌다.

## 발표물 품질 원칙

- 구매액 차이를 알 수 없으므로 막대 길이, 면적, 원 크기로 순위 간 격차를 표현하지 않았다.
- 순위 자체만 순서형 텍스트/표로 표현했다.
- ‘소비량’, ‘선호도’, ‘시장 점유율’이라는 표현을 해당 지표의 측정값처럼 사용하지 않았다.
- 이 자료만으로 지역 브랜드 충성도, 가격 효과, 유통 효과 또는 인과관계를 주장하지 않았다.
- 과거 자료나 부산 지역 회사 점유율 수치는 기간·측정 단위가 달라 현재 권역별 브랜드 순위와 합산하지 않았다.

## 재현 검수

- `node scripts/build_deck.mjs`로 PPTX와 HTML을 재생성한다.
- 생성된 PPTX는 PowerPoint COM으로 열어 구조/슬라이드 수/파일 열림 여부를 확인한다.
- HTML은 내장된 방향키, 이전·다음, 진행률, 전체 화면, 터치 스와이프 동작을 포함한다. anime.js는 CDN을 통해 로드되므로 오프라인에서는 전환 애니메이션만 비활성화될 수 있다.
